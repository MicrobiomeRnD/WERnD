# Microbiome R&D Center

이 저장소는 GitHub Pages로 정적 웹사이트를 배포하기 위한 예시입니다.

## 배포 방법
1. 이 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Settings > Pages로 이동합니다.
3. Source를 "GitHub Actions"로 선택합니다.
4. 저장하면 자동으로 Pages 배포가 시작됩니다.
5. 배포가 완료되면 아래 주소로 접속할 수 있습니다.
   - https://microbiomernd.github.io/MicrobiomeRnD/

## 포함된 파일
- index.html: 메인 페이지
- updates.html: Updates 상세 페이지
- .github/workflows/deploy.yml: GitHub Pages 자동 배포 설정
